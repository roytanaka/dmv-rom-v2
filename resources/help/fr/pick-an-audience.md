# Choisir une audience

Choisissez les destinataires d'une diffusion. L'application dresse la liste des membres pour vous.

## Ouvrir le menu

1. Sélectionnez **Courriel** sur une page de groupe, un horaire, un quart ou le répertoire.

    ![Le menu Courriel d'une page de groupe : les audiences de la liste, les responsables, les sous-groupes et Choisir des personnes](01.png)

2. Lisez le menu. Chaque ligne nomme une audience et le nombre de membres qu'elle joint.
3. Sélectionnez l'audience que vous voulez.

## Ce que veut dire chaque audience

- **Tout le groupe** joint chaque membre en règle. **Tout le groupe, congés compris** ajoute les membres en congé. Tout·e membre du groupe peut les choisir.
- Un statut, comme **Régulier·ère** ou **Stagiaire**, joint les membres du groupe qui ont ce statut. **Actifs** joint les membres au statut Régulier·ère.
- **Les responsables du groupe** joint toute personne qui détient un rôle dans le groupe. Le nom d'un sous-groupe joint la liste de ce groupe. Seul·es les responsables du groupe peuvent choisir ces audiences.
- **Inscriptions à ce quart** joint les membres inscrits à ce quart. Seul·e le ou la responsable de l'horaire ou la présidence peut la choisir.
- **Tous les membres** et les autres audiences à l'échelle de l'organisme joignent tout le DMV. Elles sont dans le menu **Courriel** du répertoire. Seul·es une présidence, un·e membre des groupes Direction, Archives ou Prix, ou un·e responsable super-niveau peuvent les choisir.
- **Conseil d’administration**, **Présidences de comité** et **Toutes les présidences** sont aussi dans le menu **Courriel** du répertoire. Tout·e membre peut les choisir.

> **Note :** Sur le groupe DMV lui-même, chaque audience joint tout le DMV. La règle à l'échelle de l'organisme décide qui peut les y choisir.

## Modifier la liste

Le champ **À** affiche un nom pour chaque membre. Retirez qui vous voulez avec le × à côté du nom. Le nom de l'audience demeure, avec une note du nombre de personnes retirées.

![L'étape Qui après un retrait : Tout le groupe, 1 retiré](02.png)

## Choisir des personnes à la main

1. Ouvrez l'onglet **Membres** de votre groupe.
2. Sélectionnez **Courriel**.
3. Sélectionnez **Choisir des personnes…**.

    ![Choisir des personnes : un champ À vide au-dessus de la liste, chaque membre avec une case à cocher](03.png)

4. Cochez les membres que vous voulez. Pour trouver un·e membre vite, cherchez par nom.

## Et ensuite

Lisez _Joindre un fichier à un courriel_ pour envoyer un fichier avec votre diffusion.
