# Générer les rapports de visites

Totalisez les visites de groupe de votre groupe par type de réservation, pour un mois ou l'exercice à ce jour. Vous avez besoin du rôle Statisticien·ne ou Président·e.

## Ouvrir le sommaire des visites

1. Ouvrez votre groupe depuis la barre latérale.
2. Sélectionnez l'onglet **Heures**.
3. Sélectionnez **Voir le rapport des heures du groupe**.
4. Sélectionnez **Sommaire des visites** dans les liens en haut.

Le rapport s'ouvre sur le mois en cours.

## Lire le sommaire des visites

Chaque ligne est un type de réservation. Elle montre trois chiffres :

- **Visites** compte une visite par guide. Une visite de groupe avec deux guides compte pour deux.
- **Visiteurs** additionne les visiteurs attendus à chaque visite de groupe.
- **Montant gagné** additionne le montant gagné de chaque visite de groupe. Un montant corrigé remplace le chiffre calculé.

Les lignes sous le tableau forment le total général :

- **Visites de groupe** additionne les types de réservation.
- **Visites régulières** compte les guides de vos autres quarts, avec les visiteurs qu'ils ont saisis.
- **Revenus d'exposition** est le montant saisi pour la période.
- **Total général** additionne les trois.

## Changer la période

Choisissez un mois sous **Mois**. Pour voir l'année à ce jour, sélectionnez **Exercice 2026 à ce jour** ou une autre année. Chaque année va d'avril au mois en cours.

## Saisir les revenus d'exposition

1. Choisissez le mois dans le **Sommaire des visites**.
2. Saisissez le montant sous **Revenus d'exposition**.
3. Sélectionnez **Enregistrer**.

Le total général inclut maintenant le montant. Videz le champ et enregistrez pour le retirer.

## Lire le détail des visites

Sélectionnez **Détail des visites** dans les liens en haut. Il divise chaque type de réservation par visite, avec un total par type.

> **Note :** Un·e Président·e ou Statisticien·ne d'un groupe parent peut lire les deux rapports, mais seul·e le·la Statisticien·ne ou Président·e de votre groupe saisit les revenus d'exposition.

## Et ensuite

Sélectionnez **Imprimer** pour une copie papier, ou lisez [Exporter un rapport en CSV](export-a-report-as-csv) pour ouvrir les chiffres dans un tableur.
