# Postuler comme bénévole

Vous postulez depuis la page de connexion, avec le code reçu lors d'une séance d'accueil.

## Entrer votre code

1. Ouvrez la page de connexion.
2. Sous le formulaire de connexion, tapez le code de candidature qu'on vous a remis.
3. Sélectionnez **Postuler**. Le formulaire de candidature s'ouvre.

Si le code n'est pas valide, la page l'indique et donne un numéro à appeler. Après cinq essais ratés, attendez une minute avant de réessayer.

> **Note :** L'entrée du code n'apparaît que lorsque le comité des adhésions accepte des candidatures.

## Remplir le formulaire

1. Tapez votre prénom, votre nom, votre courriel et votre téléphone principal. Ces quatre champs sont obligatoires.
2. Incluez l'indicatif régional dans votre numéro de téléphone.
3. Ajoutez votre adresse, votre numéro de membre du ROM et sa date d'expiration, et une personne à joindre en cas d'urgence, si vous les avez.
4. Cochez les langues que vous parlez, lisez ou écrivez. Vous pouvez ajouter une autre langue.
5. Sélectionnez **Envoyer la candidature**.

Une page confirme que votre candidature est arrivée. Le comité des adhésions communique avec vous pour fixer une entrevue. L'application ne vous envoie aucun courriel.

> **Astuce :** Sélectionnez **English** en haut du formulaire pour postuler en anglais.
