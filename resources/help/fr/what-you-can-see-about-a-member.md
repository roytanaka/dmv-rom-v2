# Ce que vous pouvez voir ou non sur un membre

Le profil d'un membre affiche des renseignements différents selon les personnes. Cet article explique ce que vous voyez et pourquoi.

## Ce que tout le monde voit

Tout membre connecté voit ces renseignements sur un profil :

- Le nom
- La photo
- Le statut
- Les groupes et les rôles

## Les coordonnées

Le courriel et les numéros de téléphone ne sont pas pour tout le monde. Vous les voyez seulement si vous êtes un dirigeant d'un groupe auquel le membre appartient. Si vous ne pouvez pas les voir, le profil indique « Les coordonnées ne vous sont pas accessibles. »

![Le profil d'un pair : nom, photo ou initiales, statut et groupes, avec la note que les coordonnées ne vous sont pas accessibles](01.png)

## Ce qui reste privé

Certains renseignements ne sont jamais affichés à un pair :

- L'adresse domiciliaire
- Les compétences

Seuls le membre lui-même et les Archives du DMV les voient. Votre propre adresse domiciliaire et vos compétences se trouvent dans vos Paramètres.
