# Requêtes enregistrées

Une requête enregistrée est un filtre nommé sur les données des membres. Le bureau des dossiers y garde ses requêtes et les exécute au besoin.

## Ouvrir vos requêtes enregistrées

1. Sélectionnez **Outils des responsables**, puis **Membres**.
2. Sélectionnez **Requêtes enregistrées**. Les requêtes sont listées par nom.

## Créer une requête

1. Sélectionnez **Nouvelle requête**.
2. Tapez un **Nom**.
3. Dans **Combiner par**, choisissez **ET** pour exiger toutes les conditions, ou **OU** pour en exiger une seule.
4. Pour chaque condition, choisissez une **Source**, un **Champ**, un **Opérateur** et une **Valeur**.
5. Sélectionnez **Ajouter une condition** pour en ajouter une autre. Une requête en compte au plus dix.
6. Sous **Afficher ces colonnes**, choisissez chaque colonne dans **Ajouter une colonne**. Le tableau les affiche dans cet ordre.
7. Choisissez le champ **Trié par**.
8. Sélectionnez **Enregistrer**. La requête s'exécute.

Une source est le dossier du membre, les adhésions, les postes au conseil ou l'historique des catégories. Une valeur vide trouve les membres dont ce champ est vide.

> **Note :** Une requête sans condition sur le **Groupe de catégories** ne liste que les membres actuels. Ajoutez une condition sur le groupe de catégories pour chercher d'autres membres.

## Exécuter une requête

1. Sélectionnez le nom de la requête, ou **Exécuter**.
2. Lisez le nombre et les conditions en haut de la page.
3. Vérifiez le tableau. Chaque ligne commence cochée.

## Exporter, imprimer des étiquettes ou envoyer les résultats

Chacune de ces actions porte sur tous les membres de la requête, cochés ou non.

1. Sélectionnez **CSV** pour télécharger les colonnes du tableau dans un fichier de tableur.
2. Sélectionnez **Étiquettes** pour ouvrir les étiquettes postales, trente par feuille d'étiquettes Avery 5160. Choisissez votre **Imprimante**, puis sélectionnez **Imprimer**. Dans la fenêtre d'impression, réglez les marges sur aucune.
3. Sélectionnez **Envoyer les résultats** pour transmettre la requête à des collègues. Choisissez chaque membre sous **Destinataires**, ajoutez une **Note** au besoin, puis sélectionnez **Envoyer**. Chacun reçoit un courriel avec un lien vers les résultats, qui ne s'ouvre qu'au bureau des dossiers, après connexion.

> **Remarque :** Une étiquette n'affiche le pays que pour une adresse hors du Canada.

## Modifier, renommer ou supprimer une requête

1. Sélectionnez **Modifier** pour changer les conditions, les colonnes ou le tri, puis sélectionnez **Enregistrer**.
2. Sélectionnez **Renommer** pour changer seulement le nom.
3. Sélectionnez **Supprimer**, puis confirmez. Les membres qu'elle listait ne changent pas.

## Et ensuite

Lisez [Les listes de membres et le dossier de membre](member-lists-and-the-member-record) pour ouvrir le dossier d'un membre.
