# Ce que veut dire « En file pour N membres »

Comprenez le message affiché après l'envoi d'un courriel.

## Après l'envoi

L'application n'envoie pas votre courriel au moment où vous sélectionnez **Envoyer**. Elle met en file un courriel par membre et les envoie par lots. L'étape **Envoyé** indique **En file pour N membres**.

## Ce qui se passe ensuite

- Un petit envoi arrive en une minute.
- Une diffusion à une grande audience peut prendre jusqu'à une heure.
- Vous recevez une copie une fois tous les courriels partis.
- La copie nomme toute personne que l'application n'a pu joindre.

> **Note :** L'application saute un·e membre dont le courriel est coupé. Votre copie nomme toute personne qu'elle n'a pu joindre.

## Et ensuite

Si un message ne semble jamais arriver, demandez à un·e responsable super-niveau de vérifier la page d'état du courriel.
