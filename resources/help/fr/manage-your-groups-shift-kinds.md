# Gérer les types de quart de votre groupe

Tenez à jour la liste des types de quart offerts par votre groupe. Vous devez avoir le rôle de responsable horaire ou de président·e.

Un type de quart est l'étiquette d'un quart, comme « Faits saillants du Musée » ou « Comptoir ».

## Ajouter un type de quart

1. Ouvrez l'onglet **Paramètres** de votre groupe.
2. Trouvez la carte **Types de quart**.

    ![La carte Types de quart : chaque type avec Renommer et Retirer, et la boîte Ajouter un type de quart](01.png)

3. Saisissez le nouveau nom sous **Ajouter un type de quart**.
4. Sélectionnez **Ajouter**.

Le nouveau type s'ajoute à la fin de la liste. Chaque nom est unique dans votre groupe.

## Renommer un type de quart

1. Sélectionnez **Renommer** à côté du type.
2. Modifiez le nom dans la boîte.
3. Sélectionnez **Enregistrer**.

Les quarts qui utilisent déjà le type affichent le nouveau nom.

## Retirer ou réactiver un type de quart

1. Sélectionnez **Retirer** à côté d'un type que vous n'offrez plus.
2. Sélectionnez **Réactiver** pour l'offrir de nouveau.

Un type retiré n'est pas offert aux nouveaux quarts. Ses quarts passés gardent le nom.

> **Note :** Il n'y a pas de suppression. Vous retirez plutôt un type, pour que ses anciens quarts gardent leur étiquette.

## Réordonner les types de quart

1. Sélectionnez la flèche vers le haut ou vers le bas à côté d'un type.
2. L'ordre détermine l'affichage des types dans le sélecteur de quart.

## Et ensuite

Lisez [Créer un horaire et ses quarts](create-a-schedule-and-shifts) pour attribuer un type à un quart.
