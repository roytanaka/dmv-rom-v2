# Saisir une réponse pour un invité

Notez une réponse donnée par téléphone ou à la porte. Cela fonctionne aussi une fois l'invitation fermée.

1. Trouvez l'invitation dans l'onglet **Organisation**.
2. Sélectionnez **Réponses**.
3. Sélectionnez **Saisir la réponse** à côté de l'invité.
4. Choisissez **Acceptée** ou **Refusée**.
5. Si vous choisissez **Acceptée**, cochez les options de l'invité.
6. Sélectionnez **Enregistrer**.

Pour répondre pour un membre qui n'est pas sur la liste, sélectionnez **Répondre pour un membre** et choisissez son nom. Il devient un invité.

> **Note :** Vous pouvez dépasser votre propre limite d'invités. La limite arrête seulement les invités qui répondent eux-mêmes.

## Et ensuite

Lisez [Écrire aux invités ayant accepté](email-accepted-guests) pour joindre tous ceux qui viennent.
