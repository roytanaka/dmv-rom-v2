# Saisir et corriger des heures

Ajoutez les heures travaillées pour un groupe hors de vos quarts, ou corrigez un nombre déjà au dossier. Tout·e membre peut le faire pour un groupe dont il·elle peut ouvrir la page.

## Comment les heures arrivent au dossier

Vous ne saisissez pas toutes les sortes d'heures :

- Les **heures planifiées** viennent de vos quarts. L'application les compte pour vous.
- Les **heures de réunion** viennent des réunions auxquelles vous avez assisté.
- Les **heures supplémentaires** sont la seule sorte que vous tapez : le travail hors des quarts et des réunions.

## Saisir des heures supplémentaires

1. Ouvrez le groupe depuis la barre latérale.
2. Sélectionnez l'onglet **Heures**.
3. Trouvez le mois voulu sous **Enregistrer des heures supplémentaires**.
4. Saisissez les heures dans **Heures à ajouter**.
5. Sélectionnez **Ajouter les heures**.

Le formulaire propose ce mois-ci et le mois dernier. « Enregistré » indique ce qui figure déjà au dossier.

> **Note :** N'ajoutez pas les quarts ni les réunions. L'application les compte déjà.

## Corriger un nombre

Saisissez un nombre négatif dans **Heures à ajouter** pour réduire le total. Le nombre s'ajoute à ce qui figure au dossier, donc un nombre négatif soustrait. Le total ne descend jamais sous zéro.

## Et ensuite

Vos mois apparaissent dans « Vos heures dans ce groupe » sous le formulaire. Un·e Président·e ou Statisticien·ne relit tout le groupe dans le rapport des heures.
