# Gérer les types de réservation de votre groupe

Tenez à jour les types de réservation qui servent à facturer les visites de groupe. Vous devez avoir le rôle de responsable des réservations ou de président·e.

Un type de réservation indique comment un client paie une visite de groupe, comme « Visite payante » ou « Poste gratuit ». Chaque type a un tarif par visiteur et un tarif par heure de guide. L'application s'en sert pour calculer ce que rapporte une visite de groupe.

## Configurer les visites de groupe

1. Ouvrez l'onglet **Paramètres** de votre groupe.
2. Trouvez la carte **Visites de groupe**.
3. Choisissez le type de quart des visites de groupe sous **Type de quart des visites de groupe**.
4. Saisissez le nom de vos horaires de visites de groupe sous **Nom de l’horaire des visites de groupe**, comme « Visites de groupe ».
5. Au besoin, saisissez une adresse sous **Copier chaque courriel de visite de groupe à**. Chaque courriel de visite de groupe y est aussi envoyé.
6. Sélectionnez **Enregistrer**.

L'horaire des visites de groupe de chaque mois prend ce nom, suivi du mois et de l'année.

## Ajouter un type de réservation

1. Sélectionnez **Ajouter un type de réservation**.
2. Saisissez le nom.
3. Entrez le tarif par visiteur et le tarif par heure de guide. Entrez 0 pour un tarif que le type ne facture pas.
4. Sélectionnez **Enregistrer**.

Le nouveau type s'ajoute à la fin de la liste. Chaque nom est unique dans votre groupe.

## Modifier un type de réservation

1. Sélectionnez **Modifier** à côté du type.
2. Changez le nom ou l'un des tarifs.
3. Sélectionnez **Enregistrer**.

## Retirer ou rétablir un type de réservation

1. Sélectionnez **Retirer** à côté d'un type que vous n'utilisez plus.
2. Sélectionnez **Rétablir** pour l'utiliser de nouveau.

Les visites de groupe qui utilisent déjà un type retiré le conservent.

> **Note :** Vous pouvez supprimer un type seulement si aucune visite de groupe ne l'utilise. Sinon, retirez-le.

## Réordonner les types de réservation

Sélectionnez la flèche vers le haut ou vers le bas à côté d'un type. L'ordre détermine comment les types s'affichent quand vous en choisissez un.

## Et ensuite

Lisez [Trouver les paramètres de votre groupe](group-settings) pour les autres cartes de l'onglet.
