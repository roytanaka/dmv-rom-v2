# Gérer la bibliothèque de documents de votre groupe

Gardez les fichiers et les liens de votre groupe en ordre, et décidez qui les lit. Vous avez besoin du rôle Bibliothécaire ou Président·e.

## Ajouter un dossier

1. Ouvrez l'onglet **Documents** de votre groupe.

    ![L'onglet Documents pour un·e bibliothécaire : la zone de téléversement, Ajouter un lien, Nouveau dossier, Gérer les étiquettes et un bouton d'actions sur chaque ligne](01.png)

2. Ouvrez le dossier qui recevra le nouveau dossier, ou restez au premier niveau.
3. Sélectionnez **Nouveau dossier**.

    ![La fenêtre Nouveau dossier : Nom, et Qui peut le lire réglé sur Membres du groupe](02.png)

4. Saisissez un **Nom**.
5. Pour un dossier de premier niveau, réglez **Qui peut le lire**.
6. Sélectionnez **Enregistrer**.

Les dossiers peuvent compter jusqu'à 5 niveaux. Un dossier placé dans un dossier de premier niveau suit le réglage de celui-ci.

## Choisir qui peut lire un dossier

1. Sélectionnez le bouton d'actions au bout de la ligne d'un dossier de premier niveau.
2. Sélectionnez **Modifier**.

    ![La fenêtre Modifier le dossier pour Natural History, lisible par tous les membres](03.png)

3. Réglez **Qui peut le lire** sur **Membres du groupe** ou **Tous les membres**.
4. Sélectionnez **Enregistrer**.

> **Note :** Les documents au premier niveau, hors de tout dossier, sont réservés aux membres du groupe.

## Téléverser des fichiers

1. Ouvrez le dossier qui recevra les fichiers.
2. Déposez les fichiers sur la zone de téléversement, ou sélectionnez **Choisir des fichiers**.

Chaque fichier affiche une barre de progression pendant le téléversement. L'application n'ajoute pas un fichier de plus de 1,5 Go ou d'un type non permis.

## Ajouter un lien

1. Sélectionnez **Ajouter un lien**.
2. Saisissez un **Titre** et une **Adresse Web**.
3. Sélectionnez **Enregistrer**.

## Modifier un document

Sélectionnez le bouton d'actions au bout de la ligne d'un document. Puis sélectionnez un élément :

![Le menu d'actions d'un document : Modifier, Remplacer le fichier, Déplacer et Supprimer](04.png)

1. Sélectionnez **Modifier** pour changer le titre et la description. Pour un lien, vous pouvez aussi changer l'adresse Web.
2. Sélectionnez **Remplacer le fichier** pour téléverser une nouvelle version. Les membres utilisent le même lien pour l'obtenir.
3. Sélectionnez **Déplacer** pour mettre le document dans un autre dossier. Choisissez le dossier sous **Déplacer vers**.

    ![La fenêtre Déplacer : la liste Déplacer vers, puis Déplacer](05.png)

4. Sélectionnez **Supprimer** pour retirer le document et son fichier. Une suppression est définitive.

## Renommer, déplacer ou supprimer un dossier

Sélectionnez le bouton d'actions au bout de la ligne d'un dossier. Sélectionnez **Renommer** ou **Modifier**, **Déplacer** ou **Supprimer**. Vous pouvez supprimer seulement un dossier vide.

## Utiliser les étiquettes

1. Sélectionnez **Gérer les étiquettes** pour ajouter, renommer ou supprimer les étiquettes de votre groupe.

    ![La fenêtre Étiquettes : chaque étiquette avec renommer et supprimer, puis Nouvelle étiquette](06.png)

2. Sélectionnez le bouton d'étiquette sous le nom d'un document.

    ![La fenêtre Étiquettes d'un document : une case pour chaque étiquette](07.png)

3. Cochez les étiquettes de ce document.
4. Sélectionnez **Enregistrer**.

Une suppression retire l'étiquette de tous les documents.

> **Astuce :** Utilisez une étiquette pour montrer un document dans plus d'une vue. Un document se trouve dans un seul dossier.

## Et ensuite

Les membres trouvent vos documents avec les étapes de [Trouver un document dans la bibliothèque d'un groupe](find-a-document-in-a-groups-library).
