# Modifier la section À propos et la bannière de votre groupe

Modifiez la description et les étapes pour se joindre sur la page de votre groupe, et choisissez son image de bannière. Vous avez besoin du rôle Secrétaire ou Président·e.

## Modifier le texte de la section À propos

1. Ouvrez votre groupe depuis la barre latérale.
2. Restez sur l'onglet **Aperçu**.
3. Sélectionnez **Modifier** dans la carte **À propos**.

    ![L'onglet Aperçu : Modifier sur la carte À propos, et Changer la bannière sur la bannière](01.png)

4. Saisissez votre description dans la boîte.
5. Sélectionnez **Enregistrer**.

    ![Le formulaire À propos : la boîte de texte, Enregistrer et Annuler](02.png)

> **Note :** Videz la boîte et enregistrez pour effacer la description.

## Écrire les étapes pour se joindre

La carte **Comment se joindre** explique aux autres membres comment se joindre à votre groupe. Chaque membre qui ouvre votre groupe peut la lire.

1. Sur l'onglet **Aperçu**, trouvez la carte **Comment se joindre** sous **En bref**.
2. Sélectionnez **Modifier** dans la carte **Comment se joindre**.
3. Saisissez les étapes pour se joindre, une par ligne.
4. Sélectionnez **Enregistrer**.

> **Note :** Videz la boîte et enregistrez pour effacer les étapes. La carte invite alors les lecteurs à communiquer avec le ou la Président·e de votre groupe.

## Choisir une bannière

1. Sélectionnez **Changer la bannière** en haut à droite de la bannière.
2. Le sélecteur s'ouvre avec six images.

    ![La fenêtre Choisir une bannière avec ses six bannières](03.png)

3. Sélectionnez la bannière que vous voulez.

Votre choix est enregistré aussitôt. Le sélecteur se ferme et votre groupe affiche la nouvelle bannière.

## Et ensuite

Les membres de votre groupe voient le nouveau texte À propos et la nouvelle bannière sur l'onglet Aperçu. Chaque membre voit la carte Comment se joindre.
