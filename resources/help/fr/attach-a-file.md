# Joindre un fichier à un courriel

Envoyez un fichier avec une diffusion ou un message direct.

## Ajouter une pièce jointe

1. Rédigez votre courriel jusqu'à l'étape **Message**.
2. Sélectionnez **Ajouter une pièce jointe**.
3. Choisissez un fichier sur votre ordinateur.
4. Vérifiez le nom et la taille du fichier dans la liste.
5. Sélectionnez **Envoyer**.

Le fichier part avec votre courriel. Pour retirer un fichier avant l'envoi, sélectionnez le × à côté de son nom.

> **Note :** Joignez jusqu'à deux fichiers, 10 Mo au total. Pour un fichier plus gros, partagez plutôt un lien vers celui-ci.

## Et ensuite

Lisez _Ce que veut dire « En file pour N membres »_ pour voir ce qui se passe après l'envoi.
