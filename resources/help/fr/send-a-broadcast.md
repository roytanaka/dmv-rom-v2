# Envoyer une diffusion à votre groupe

Écrivez à tout votre groupe d'un coup.

## Envoyer la diffusion

1. Ouvrez votre groupe depuis la barre latérale.
2. Sélectionnez **Courriel** dans la barre d'onglets.

    ![Le menu Courriel ouvert sous la barre d'onglets : chaque audience avec le nombre de membres qu'elle joint](01.png)

3. Sélectionnez **Tout le groupe** dans le menu.

    ![L'étape Qui pour Tout le groupe : un nom pour chaque membre, chacun avec un ×](02.png)

4. Vérifiez la liste **À**. Retirez qui vous voulez avec le × à côté du nom.
5. Sélectionnez **Suivant**.
6. Rédigez votre objet et votre message.

    ![L'étape Message : l'audience, l'objet et le message remplis, et Envoyer](03.png)

7. Sélectionnez **Envoyer**.

    ![Après l'envoi : En file pour 23 membres, et une note indiquant que vous recevez une copie](04.png)

L'application envoie un courriel à chaque membre. Vous recevez une copie une fois la livraison terminée.

> **Note :** La diffusion part sous le nom de votre groupe. Les réponses vous parviennent.

## Et ensuite

Lisez _Choisir une audience_ pour joindre un autre ensemble de membres. Lisez _Joindre un fichier à un courriel_ pour envoyer un fichier avec.
