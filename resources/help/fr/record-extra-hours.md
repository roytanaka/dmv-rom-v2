# Enregistrer des heures supplémentaires pour un mois

Enregistrez les heures passées à aider un groupe en dehors de vos quarts planifiés.

## Enregistrer vos heures

1. Ouvrez un groupe depuis le tableau de bord ou le rail.
2. Sélectionnez l'onglet **Heures**.
3. Trouvez le mois voulu. Le formulaire propose ce mois-ci et le mois dernier.
4. Saisissez les heures dans **Heures à ajouter**.
5. Sélectionnez **Ajouter les heures**.

Les heures s'ajoutent à ce qui est déjà enregistré pour ce mois.

> **Note :** Les quarts planifiés et les réunions sont déjà comptés. N'ajoutez que les heures effectuées en dehors de ceux-ci.

## Corriger une erreur

Saisissez un nombre négatif dans **Heures à ajouter** pour réduire le total. Le groupe ne descend jamais sous zéro.

## Et ensuite

Vos heures enregistrées apparaissent dans « Vos heures dans ce groupe » sous le formulaire. Ouvrez Mes heures pour lire votre année complète, tous groupes confondus.
