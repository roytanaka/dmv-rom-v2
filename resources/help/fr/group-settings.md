# Trouver les paramètres de votre groupe

Ouvrez l'onglet **Paramètres** pour changer le fonctionnement de votre groupe. Vous avez besoin du rôle Responsable horaire ou Président·e.

## Ouvrir l'onglet Paramètres

1. Ouvrez votre groupe depuis la barre latérale.
2. Sélectionnez l'onglet **Paramètres**. C'est le dernier onglet de la bande.

L'onglet affiche une carte pour chaque paramètre que vous pouvez changer.

## Ce que contient l'onglet

Un paramètre est une valeur que vous réglez une fois. L'application l'utilise ensuite. L'onglet contient cinq cartes :

- **Rappels de quart** active les rappels par courriel et règle le nombre de jours de préavis.
- **Alerte de poste vacant** signale par courriel à votre groupe les quarts surveillés sans personne d'inscrit.
- **Quarts en libre-service** permet aux membres de créer leurs propres quarts.
- **Types de quart** contient la liste des types offerts par votre groupe.
- **Objets** contient la collection que les membres apportent sur le plancher.

Les cinq cartes s'affichent seulement si votre groupe utilise les horaires.

## Où se trouvaient les paramètres

Ces cartes se trouvaient dans l'onglet **Horaire**. Elles sont ici pour que l'onglet Horaire s'ouvre sur vos horaires.

Les horaires, les quarts et les inscriptions restent dans l'onglet **Horaire**. Vous les créez et les modifiez toujours là.

> **Note :** Seul·e un·e membre qui peut changer un paramètre voit l'onglet Paramètres. Les autres membres ne le voient pas.

## Et ensuite

Lisez _Configurer les rappels et l'alerte de poste vacant de votre groupe_ pour remplir les deux premières cartes.
