# Générer le rapport des heures de votre groupe

Relisez les heures de chaque membre de votre groupe pour une année financière. Vous avez besoin du rôle Statisticien·ne ou Président·e.

## Ouvrir le rapport

1. Ouvrez votre groupe depuis la barre latérale.
2. Sélectionnez l'onglet **Heures**.
3. Sélectionnez **Voir le rapport des heures du groupe**.

Le rapport s'ouvre sur l'année financière en cours.

## Lire le rapport

Chaque ligne est un·e membre. Chaque colonne est un mois, d'avril à mars. La dernière colonne est le cumul annuel du·de la membre.

Deux lignes se trouvent sous le tableau :

- **Ce groupe** totalise le groupe seul.
- **Sous-groupes compris** ajoute chaque groupe en dessous.

## Changer l'année financière

Sélectionnez une année sous **Année financière** pour en relire une plus ancienne. Le tableau se recharge pour cette année.

## Voir d'autres vues

Les liens en haut ouvrent d'autres coupes des mêmes heures : **Par mois**, **Historique du membre**, **Heures supplémentaires** et **Heures de réunion**.

> **Note :** Un·e Président·e ou Statisticien·ne d'un groupe parent relit aussi ce rapport. Le rôle porte sur tout l'arbre.

## Et ensuite

Sélectionnez **Imprimer** pour une copie papier, ou lisez _Exporter un rapport en CSV_ pour ouvrir les nombres dans un tableur.
