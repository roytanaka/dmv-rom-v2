# Publier une nouvelle

Publiez une nouvelle d'un groupe dans le fil de tout le DMV. Vous devez avoir le rôle de responsable des nouvelles.

## Rédiger une publication

1. Sélectionnez **Nouvelles** dans la barre supérieure.
2. Sélectionnez **Nouvelle publication**.
3. Choisissez le groupe pour lequel vous publiez dans **Groupe de publication**.
4. Saisissez un **Titre** et un **Contenu**.
5. Sélectionnez **Publier**.

Votre publication apparaît en haut du fil pour chaque membre.

## Modifier ou supprimer une publication

Vos propres publications portent les commandes **Modifier** et **Supprimer**. Sélectionnez **Modifier** pour changer le titre ou le contenu. Sélectionnez **Supprimer** pour retirer la publication. La suppression vous demande d'abord de confirmer.

## Et ensuite

Votre publication apparaît dans le fil comme les autres. Lisez « Lire les nouvelles » pour voir la vue du lecteur.
