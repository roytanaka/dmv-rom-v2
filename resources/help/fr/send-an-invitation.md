# Envoyer une invitation

Écrivez à vos invités et ouvrez l'invitation aux réponses.

## L'envoyer

1. Ajoutez d'abord vos invités. Vous ne pouvez pas envoyer à une liste vide.
2. Trouvez le brouillon dans l'onglet **Organisation**.
3. Sélectionnez **Envoyer**.

    ![L'étape Qui du panneau de courriel avec Tous les invités et un nom pour chaque invité](01.png)

4. Vérifiez la liste **À** et sélectionnez **Suivant**.

    ![L'étape Message du panneau de courriel avec l'objet et le message remplis à partir de l'invitation](02.png)

5. Modifiez l'objet et le message. L'application les remplit à partir de votre invitation.
6. Sélectionnez **Envoyer**.

    ![Le panneau de courriel après l'envoi, avec les courriels en file pour 24 membres](03.png)

L'invitation est maintenant ouverte. Chaque invité reçoit son propre courriel, avec un lien pour répondre. La livraison peut prendre jusqu'à une heure. Vous recevez une copie quand elle est terminée.

![L'onglet Organisation avec l'invitation marquée Ouverte et une action Renvoyer](04.png)

> **Note :** Pour arrêter, fermez le panneau de courriel avant de sélectionner **Envoyer**. L'invitation reste un brouillon.

Le courriel part sous votre nom, et les réponses à ce courriel vous parviennent. Votre texte reste dans la langue où vous l'avez écrit.

## L'envoyer de nouveau

Les changements n'envoient aucun courriel d'eux-mêmes. Pour annoncer un changement aux invités ou relancer une réponse :

1. Trouvez l'invitation dans l'onglet **Organisation**.
2. Sélectionnez **Renvoyer**.
3. Sélectionnez **Tous les invités** ou **Invités sans réponse**.
4. Vérifiez la liste **À** et sélectionnez **Suivant**.
5. Modifiez l'objet et le message.
6. Sélectionnez **Envoyer**.

Utilisez **Invités sans réponse** pour joindre un invité ajouté après l'envoi.

## Et ensuite

Lisez [Suivre les réponses](track-the-replies) pour voir qui vient.
