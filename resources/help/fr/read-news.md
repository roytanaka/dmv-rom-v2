# Lire les nouvelles

Lisez les nouvelles publiées par les groupes de tout le DMV.

## Ouvrir le fil

1. Sélectionnez **Nouvelles** dans la barre supérieure.
2. Le fil s'ouvre avec l'élément le plus récent en premier.

![Le fil des nouvelles avec l'élément le plus récent en haut](01.png)

## Lire un élément

Chaque élément affiche :

- Le titre
- Le message
- Le groupe qui l'a publié, et la date

Si aucun groupe n'a encore publié, le fil indique « Aucune nouvelle pour le moment. »

## Et ensuite

Vous publiez des nouvelles pour un groupe ? Lisez « Publier une nouvelle ».
