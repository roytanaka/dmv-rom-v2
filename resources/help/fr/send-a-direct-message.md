# Écrire un message direct à un·e membre

Écrivez à un·e autre membre sans connaître son adresse courriel.

## Envoyer le message

1. Ouvrez le répertoire depuis la barre du haut.
2. Sélectionnez le ou la membre que vous voulez joindre.

    ![Le profil d'un·e membre : le bouton Écrire à, à droite de l'en-tête](01.png)

3. Sélectionnez le bouton **Écrire à** dans l'en-tête du profil. Le bouton affiche le prénom du ou de la membre.

    ![La première étape : le ou la seul·e membre à qui vous écrivez, et une note indiquant que votre adresse de réponse est visible](02.png)

4. Vérifiez le nom. Sélectionnez **Suivant**.
5. Rédigez votre objet et votre message.

    ![L'étape Message : l'objet et le message remplis, avec Retour et Envoyer](03.png)

6. Sélectionnez **Envoyer**.

    ![Après l'envoi : En file pour 1 membre, et une note indiquant que vous recevez une copie](04.png)

L'application livre votre message. Votre propre adresse l'accompagne comme adresse de réponse, pour que le ou la membre puisse vous répondre.

> **Note :** Vous ne pouvez pas vous écrire à vous-même. Le bouton **Écrire à** est masqué sur votre propre profil.

## Et ensuite

Lisez _Envoyer une diffusion à votre groupe_ pour écrire à plusieurs membres à la fois. Lisez _Ce que veut dire « En file pour N membres »_ pour voir ce qui se passe après l'envoi.
