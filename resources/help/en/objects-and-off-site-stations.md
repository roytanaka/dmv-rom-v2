# Objects and off-site stations

Set up self-serve scheduling for your Group. You name the Objects Members hand out and mark the stations that run off-site. You need the Scheduler or Chair role.

## Turn on self-serve shifts

1. Open your Group from the rail.
2. Select the **Settings** tab.
3. Find the **Self-serve shifts** card.
4. Turn on **Let members write their own shifts**.
5. Set the **Minutes per unit**. Gallery Interpreters use 45.
6. Select **Save**.

Members can now write their own shifts on your published Schedules.

## Maintain the Objects

The **Objects** card holds the handling collection Members take onto the floor.

1. Type a name under **Add an object**.
2. Select **Add**.
3. Select **Rename** to change a name.
4. Select **Retire** to keep an Object off new sign-ups. Its past sign-ups keep the name.
5. Select **Reinstate** to bring a retired Object back.
6. Use **Move up** and **Move down** to set the order Members see.

> **Note:** When your Group has an active Object, a self-serve shift must carry at least one. A Member cannot pick an Object another shift already holds at an overlapping time.

## Mark a station off-site

An off-site station holds its Objects for a day either side of the shift. Use it for events such as the CNE.

1. Find the station on the **Shift kinds** card.
2. Turn on **Off-site**.

The hold now runs from the day before to the day after each shift on that station.

## Build an event

An event is a set of shifts on an off-site station.

1. Select the **Scheduling** tab.
2. Open the Schedule for the event.
3. Add a shift for each slot. Choose the off-site station as the **Kind**.
4. Set the capacity to one for each seat a Member takes.

A Member takes a seat and picks their Objects. The off-site hold does the rest.
