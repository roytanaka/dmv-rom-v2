# Add or remove many Shifts at once

Create Shifts at set times on chosen weekdays across a date range. You can also remove a batch made this way. You need the Scheduler or Chair role.

## Create Shifts in bulk

1. Open your Group's **Scheduling** tab.
2. Open the Schedule you want to fill.

    ![An opened Schedule: Bulk shifts beside New shift](01.png)

3. Select **Bulk shifts**.

    ![The Bulk-create shifts dialog: weekdays, times with Add time, dates, capacity, and kind, then Create shifts and Delete matching](02.png)

4. Under **Days of the week**, check each weekday to schedule.
5. Set the **Start time** and **End time**.

    > **Tip:** To make the Shift at more than one time a day, select **Add time**. Set the times on each new row.

6. Set the **From date** and **To date** for the range.
7. Set the **Capacity** and a **Kind** if your Group uses them.
8. Select **Create shifts**.

One Shift lands at each time on every chosen weekday in the range. A report tells you how many were made.

> **Note:** The report also lists any day and time it skipped, and why. A day outside the Schedule's range is skipped.

## Remove Shifts in bulk

1. Set the same filter you used to create the Shifts, with the same times.
2. Select **Delete matching**.
3. Confirm when the app asks.

The app removes every empty Shift that matches the filter. A Shift with Members signed up is kept.

## What next

Members sign up on their own. To place a named Member yourself, read [Assign a Member to a Shift](assign-a-member-to-a-shift).
