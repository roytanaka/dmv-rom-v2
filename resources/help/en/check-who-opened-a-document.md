# Check who opened a Document

Find out which Members opened a file, and when. You need the super-tier grant.

## Open the log

1. In the side menu, under **Officer Tools**, select **Download log**.

The log lists every download and link opened, newest first. Each page shows fifty rows.

## Narrow the list

1. Select a **Group** to see only that Group's Documents.
2. Select a **Member** to see only what that Member opened.
3. Set **From** and **To** to limit the dates. Both days are included.
4. Type part of a name in **File name**, then select **Search**.

The filters work together. Select **Clear filters** to see every row again.

## Read a row

- **File name** opens the folder that holds the Document.
- A deleted Document keeps its name, marked **Deleted**, with no link.
- **Deleted Member** or **Deleted Group** means that record is gone. The row stays.

> **Note:** The log is read-only. Nobody can edit or remove a row.

## What next

To open the file from its folder, read [Find a document in a Group's library](find-a-document-in-a-groups-library).
