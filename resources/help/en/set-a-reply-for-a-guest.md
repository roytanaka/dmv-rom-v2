# Set a Reply for a Guest

Record an answer you get by phone or at the door. It works after the Invitation is Closed.

1. Find the Invitation on the **Hosting** tab.
2. Select **Replies**.
3. Select **Set reply** beside the Guest.
4. Pick **Accepted** or **Declined**.
5. If you pick **Accepted**, tick the Guest's Options.
6. Select **Save**.

![The Set reply dialog with a Guest's Reply and Options](01.png)

To answer for a Member who is not on the list, select **Reply for a Member** and pick their name. They become a Guest.

> **Note:** You can go over your own Guest limit. The limit stops only Guests who reply for themselves.
