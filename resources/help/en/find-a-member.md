# Find a Member

Find one Member in the Directory and open their profile.

## Search by name

1. Select **Directory** in the top bar.

    ![The Directory: the search box above the roster](01.png)

2. Type a name in the search box.
3. The list narrows as you type. It matches a first or last name.

## Narrow the list

Filter the list to one Group with **Filter by Group**. Sort the list with **Sort by**: last name or first name.

> **Tip:** On a wide screen, select a letter in the A–Z rail to jump down the list.

## Open a profile

Select a Member's name to open their profile.

![A Member's profile: name, standing, the Contact details card, and Groups and roles](02.png)
