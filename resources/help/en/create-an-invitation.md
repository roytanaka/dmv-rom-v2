# Create an Invitation

Set up an occasion as a Draft. Nobody else sees it until you send it.

You need Full access to host. Without it, you do not see the **Hosting** tab.

## Create the Draft

1. Select **Invitations** in the top bar.
2. Select the **Hosting** tab.
3. Select **New invitation**.
4. Enter the name, date, start time, end time, and description.
5. To cap the number of Guests who can accept, enter a **Guest limit**.
6. To offer a lunch or a tour, select **Add option** and enter its name. Repeat for each Option.
7. Select **Save**.

The Invitation appears on the Hosting tab as a Draft.

> **Note:** The Guest limit counts Accepted Replies only. Options do not count, and each Option has no limit of its own.

## Change or remove an Invitation

Find the Invitation on the Hosting tab.

- Select **Edit** to change it. Guests get no email about the change.
- Select **Move to Draft** to hide an Open Invitation from its Guests. Their Replies stay.
- Select **Delete** to remove it. Guests get no email.

Past Invitations stay on the Hosting tab.
