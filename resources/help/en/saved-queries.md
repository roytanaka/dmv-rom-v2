# Saved queries

A Saved query is a named filter over Member data. The Records office keeps its queries here and runs them when it needs a list.

## Open your Saved queries

1. Select **Officer Tools**, then **Members**.
2. Select **Saved queries**. The queries are listed by name.

## Create a query

1. Select **New query**.
2. Type a **Name**.
3. In **Match**, choose **AND** to need every condition, or **OR** to need any one.
4. For each condition, choose a **Source**, a **Field**, an **Operator** and a **Value**.
5. Select **Add a condition** for another one. A query holds up to ten.
6. Under **Show these columns**, pick each column from **Add a column**. The table shows them in that order.
7. Choose the **Sorted by** field.
8. Select **Save**. The query runs.

A source is the Member record, Memberships, board positions or the Category history. An empty value finds Members with that field blank.

> **Note:** A query with no condition on **Category group** lists Current Members only. Add a Category group condition to search other Members.

## Run a query

1. Select the query's name, or **Run**.
2. Read the count and the conditions at the top.
3. Check the table. Every row starts with its box ticked.

## Export, print labels or email the results

Each of these covers every Member the query lists, ticked or not.

1. Select **CSV** to download the table's columns as a spreadsheet file.
2. Select **Labels** to open the mailing labels, thirty to a sheet of Avery 5160 labels. Choose your **Printer**, then select **Print**. In the print window, set the margins to none.
3. Select **Email results** to send the query to colleagues. Pick each Member under **Send to**, type a **Note** if you like, then select **Send**. Each gets an email with a link to the results, which opens only for the Records office after sign-in.

> **Note:** A label shows the country only for an address outside Canada.

## Change, rename or delete a query

1. Select **Edit** to change the conditions, columns or sort, then select **Save**.
2. Select **Rename** to change only the name.
3. Select **Delete**, then confirm. The Members it listed stay as they are.
