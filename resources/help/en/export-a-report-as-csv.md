# Export a report as CSV

Download a report as a CSV file to open it in a spreadsheet. This works on any hours report you can read.

## Export the report

1. Open the report you want.
2. Choose the **Fiscal year** you need.
3. Select **Export CSV**.

Your browser downloads the file. The name says which report and which fiscal year it holds.

## Open the file

Open the CSV in Excel, Numbers, or Google Sheets. The columns match the report: one Member per row, one month per column, and a year-to-date total.

> **Tip:** Set the fiscal year before you export. The file holds the year the report is showing.

## What next

Every report page has its own **Export CSV**. Read _The org-wide reports_ to see which DMV-wide reports you can export.
