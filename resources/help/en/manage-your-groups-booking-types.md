# Manage your Group's booking types

Keep the booking types your Group bills group tours by. You need the Booker or Chair role.

A booking type is how a client pays for a group tour, such as Tour Paid or Spot Free. Each type has a rate per visitor and a rate per docent-hour. The app uses them to work out what a group tour earns.

## Set up group tours

1. Open your Group's **Settings** tab.
2. Find the **Group tours** card.
3. Pick the shift kind group tours use under **Group-tour shift kind**.
4. Type the name for your group-tour Schedules under **Group-tour schedule name**, such as "Group tours".
5. Optionally, enter an address under **Copy every group-tour email to**. Every group tour email goes there too.
6. Select **Save**.

Each month's group-tour Schedule takes this name, followed by the month and year.

## Add a booking type

1. Select **Add booking type**.
2. Type the name.
3. Enter the rate per visitor and the rate per docent-hour. Enter 0 for a rate the type does not charge.
4. Select **Save**.

The new type joins the end of the list. Each name is unique within your Group.

## Change a booking type

1. Select **Edit** beside the type.
2. Change the name or either rate.
3. Select **Save**.

## Retire or restore a booking type

1. Select **Retire** beside a type you no longer use.
2. Select **Restore** to use it again.

Group tours that already use a retired type keep it.

> **Note:** You can delete a type only if no group tour uses it. Otherwise, retire it.

## Reorder the booking types

Select the up or down arrow beside a type. The order sets how the types appear when you pick one.
