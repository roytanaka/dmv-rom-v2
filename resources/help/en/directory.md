# What the Directory is for

The Directory is the roster of DMV Members. Every signed-in Member can read it.

## What each row shows

Each row shows a Member's photo, name, Groups, and standing. Select a name to open that Member's profile.

![The Directory: the search box, the Group filter, the Sort by toggle, and the roster with photo or initials, name, Groups, and standing](01.png)

## Finding your way around

Search by name, or filter the list to one Group. Sort by last name or first name. On a wide screen, the A–Z rail jumps you to a letter.

When you filter to one Group, a **Role** column shows each Member's roles in that Group. The Groups column becomes **Other Groups** and lists only their other Groups.

## Picking a list

The list select after the Group filter picks which Members the Directory shows. **All Members** is the default. You can also pick the **DMV Board of Directors**, **Committee Chairs**, or **Committee and DMV SubCommittee Chairs**. To see each Board member's roles, pick the Board list, then filter to the Executive Group.

Records and Officers see more lists: All Members +LOA, Active and Provisional Members, and one list for each standing. An Officer is a Chair, Secretary, Treasurer, or Statistician in any Group. Provisional and PreActive Members show only in these lists.

Each list holds the same Members as the email Audience with the same name. A Member who turned off email still shows in the list.

## What you can see

The Directory never shows contact details. What you see on a profile depends on your role. Read [What you can and cannot see about a Member](what-you-can-see-about-a-member) for the tiers.
