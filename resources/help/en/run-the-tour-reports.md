# Run the tour reports

Total your Group's group tours by booking type for a month or the fiscal year so far. You need the Statistician or Chair role.

## Open Tour summary

1. Open your Group from the Left Side Bar.
2. Select the **Hours** tab.
3. Select **View the group hours report**.
4. Select **Tour summary** in the links across the top.

The report opens on the current month.

## Read Tour summary

Each row is one booking type. It shows three figures:

- **Tours** counts one tour per docent. A group tour with two docents counts as two.
- **Visitors** adds up the visitors expected on each group tour.
- **Earned** adds up each group tour's Earned. A corrected Earned replaces the worked-out figure.

The rows below the table build the grand total:

- **Group tours** adds up the booking types.
- **Scheduled tours** counts the docents on your other shifts, with the visitors they recorded.
- **Exhibition revenue** is the figure entered for the period.
- **Grand total** adds all three.

## Change the period

Pick a month under **Month**. To see the year so far, select **Fiscal 2026 to date** or another year. Each year runs from April to the current month.

## Enter exhibition revenue

1. Pick the month on **Tour summary**.
2. Enter the amount under **Exhibition revenue**.
3. Select **Save**.

The grand total now includes the amount. Empty the field and save to remove it.

## Read Tour detail

Select **Tour detail** in the links across the top. It splits each booking type by tour, with a total for each type.

> **Note:** A Chair or Statistician of a parent Group can read both reports, but only your Group's Statistician or Chair enters exhibition revenue.

## What next

Select **Print** for a paper copy, or read [Export a report as CSV](export-a-report-as-csv) to open the numbers in a spreadsheet.
