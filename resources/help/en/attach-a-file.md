# Attach a file to an email

Send a file with a Broadcast or a Direct message.

## Add an attachment

1. Write your email as far as the **Message** step.
2. Select **Add attachment**.
3. Choose a file from your computer.

    ![The Message step: the file's name and size under Attachments, with an × to remove it](01.png)

4. Check the file name and size in the list.
5. Select **Send**.

The file goes out with your email. To drop a file before you send, select the × beside its name.

> **Note:** Attach up to two files, 10 MB in total. For a larger file, share a link to it instead.
