# Turn off all email to a Member

Records can silence every email to one Member. You set it from the Member's profile.

## Set the No email flag

1. Open the Directory from the top bar.
2. Select the Member.
3. Find the **Member administration** card. It sits below the Member's Groups.
4. Select the **No email** checkbox to silence all mail to the Member.
5. Clear the checkbox to let mail reach the Member again.

## What the flag stops

A Member with the flag gets no mail of any kind:

- Broadcasts
- Direct messages
- Reminders
- Notices

> **Note:** This is a Records decision, not the Member's own choice. The flag never shows on the Member's own profile. A sender is not told; they learn a Member is unreachable only by writing.
