# Manage your Group's shift kinds

Keep the list of shift kinds your Group offers. You need the Scheduler or Chair role.

A shift kind is the label on a Shift, such as "Museum Highlights" or "Desk".

## Add a shift kind

1. Open your Group's **Settings** tab.
2. Find the **Shift kinds** card.
3. Type the new name under **Add a shift kind**.
4. Select **Add**.

The new kind joins the end of the list. Each name is unique within your Group.

## Rename a shift kind

1. Select **Rename** beside the kind.
2. Edit the name in the box.
3. Select **Save**.

Shifts that already use the kind show the new name.

## Retire or reinstate a shift kind

1. Select **Retire** beside a kind you no longer offer.
2. Select **Reinstate** to offer it again.

A retired kind is not offered for new Shifts. Its past Shifts keep the name.

> **Note:** There is no delete. You retire a kind instead, so its old Shifts keep their label.

## Reorder the shift kinds

1. Select the up or down arrow beside a kind.
2. The order sets how the kinds appear in the Shift picker.
