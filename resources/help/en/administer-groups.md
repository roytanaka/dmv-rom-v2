# Administer Groups

Create Groups, change how they are set up, and archive the ones that have finished. You need the super-tier grant.

## Open DMV Settings

1. In the Left Side Bar, select **DMV Settings** under Officer Tools.
2. The **Groups** section shows every Group in the organisation as a tree.

Each row shows the Group's name, kind, capabilities and status. The capability letters are spelled out under the tree. Archived Groups stay in the tree with an **Archived** badge. Clear **Show archived Groups** to hide them. Type in **Find a Group** to filter the tree by name. Select the arrow beside a Group to fold or unfold the Groups under it.

The root row reads **Set by officers** and Container rows read **No page**. They have no settings page of their own.

## Create a Group

1. Select **Create a Group**.
2. Enter a name and an address. The address is the end of the Group's web address, and it never changes.
3. Choose the section, then the parent. The parent list shows only that section and the Groups under it.
4. Choose a kind.
5. Select **Create**.

The new Group's settings page opens. Everything else starts switched off, so set it up next.

## Change a Group's setup

1. Select the Group's name in the tree.
2. Change the fields you need: name, section and parent, kind, listing, logo, dates, capabilities, visitor figures and hours multiplier.
3. Select **Save changes** in the bar at the bottom.

To move a Group, choose the section first, then the parent. A new section sets the parent to the section itself.

The Left Side Bar picks up the change on the next page. The bar shows who last saved the page, and when. Select **Discard** to put the saved values back. If a field has a problem, the bar counts the problems and the section list on the left marks the section.

On a wide screen, the section list on the left jumps to each part of the form.

Under each capability that is switched on, the page shows how many records the Group has for it. Switch the capability off and the line says how many records become hidden. Nothing is deleted.

> **Note:** You cannot switch off a capability while a role in the Group needs it. The error names the role. Reassign that role first.

Choosing the Container kind takes the Group's page away. Its address then answers "not found".

> **Note:** A Group that holds a Stewardship cannot become a Container or end before today. The error names the Stewardship. Move it to another Group first.

## Archive a Group

Archive a Group when its work is done. Members can still read everything in it. Nobody can add or change anything there. It leaves the Left Side Bar.

1. Open the Group's settings page.
2. Under **Archive**, select **Archive this Group**.
3. Select **Archive** to confirm.

The settings form turns read-only. A banner at the top says the Group is archived, and an **Archived** badge appears beside the name.

> **Note:** A Group that holds a Stewardship cannot be archived. The error names the Stewardship. Move it to another Group first.

To bring a Group back, open its settings page and select **Unarchive** in the banner. It returns to the Left Side Bar and takes changes again.

Groups are never deleted. Archive a Group instead.
