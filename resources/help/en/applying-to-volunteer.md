# Apply to volunteer

You apply to volunteer on the **Apply to volunteer** page, with the code you got at an intake meeting.

## Enter your code

1. Open the address on your intake-meeting handout.
2. Type the Applicant code you were given.
3. Select **Continue**. The application form opens.

If the code is wrong, the page says so and gives a number to call. After five wrong tries, wait a minute before you try again.

> **Tip:** You can also select **Start here** on the sign-in page.

> **Note:** When the Membership Committee is not taking applications, the page says so. It gives a number to call.

## Fill in the form

1. Type your first name, last name, email, and primary phone. These four are required.
2. Include the area code in your phone number.
3. Add your address, your ROM membership number and expiry, and an emergency contact if you have them.
4. Tick the languages you speak, read, or write. You can add one other language.
5. Select **Send application**.

A page confirms that your application arrived. The Membership Committee contacts you to set up an interview. You get no email from the app.

> **Tip:** Select **Français** at the top of the form to apply in French.
