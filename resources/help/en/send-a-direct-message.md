# Send a Direct message to a Member

Write to one other Member without knowing their email address.

## Send the message

1. Open the Directory from the top bar.
2. Select the Member you want to reach.

    ![A Member's profile: the Message button at the right of the header](01.png)

3. Select the **Message** button in the profile header. The button shows the Member's first name.

    ![The first step: the one Member you write to, and a note that your reply address shows](02.png)

4. Check the name. Select **Next**.
5. Write your subject and message.

    ![The Message step: the subject and message filled in, with Back and Send](03.png)

6. Select **Send**.

    ![After you send: Queued for 1 member, and a note that you get a copy](04.png)

The app delivers your message. Your own address rides along as the reply address, so the Member can write back to you.

> **Note:** You cannot message yourself. The **Message** button is hidden on your own profile.
